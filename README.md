# JSTV-myself · 红果短剧独立源

本订阅仅保留「红果短剧·独立版」。适用于支持 CatPawOpen Node.js 订阅源的 JSTV，提供真人短剧、漫剧、AI 剧的分类、搜索、分集与播放。

## 添加订阅

在 JSTV 的「订阅」→「＋」→「添加订阅」中填写：

```text
https://raw.githubusercontent.com/luoyan333/JSTV-myself/main/index.js.md5
```

名称可填写「红果短剧独立源」。添加后选择该订阅，再进入「红果短剧·独立版」。

订阅只托管脚本，视频由设备向内容平台请求。无需另外部署服务器，也无需红果账号登录。GitHub 原始文件需要在设备当前网络中可访问。

## 功能

- 真人短剧、漫剧、AI 剧分类与筛选。
- 官方 App 搜索，首屏失败时回退官网网页搜索。
- 分集列表；自动选择最高可用画质，以及最高 720P、480P 两档。
- 视频分段读取、拖动进度与切集。
- 片源不提供兼容的所选画质时明确报错，不以高画质冒充低画质。

## 1.0.3 JSTV 启动兼容修复（2026-11-06）

1.0.2 的 Unicode 属性正则不兼容 JSTV 1.17 内置的无 ICU NodeMobile 18.20.4，导致源无法加载、订阅页转圈。1.0.3 改用显式字符范围，并自行处理全角字符；保留搜索分页和续季补全。已用 JSTV 自带 NodeMobile 通过语法、搜索逻辑和真实请求测试，并在 macOS JSTV 1.17 中确认订阅入口恢复、“觉醒伪神”显示第 1—8 季；第 6、8 季的第 2 集均实际播放，显示 1080P / HEVC 硬解，分别播放约 15、17 秒。本次为抽样验收，不代表全部分集完整播放验证。

## 1.0.2 搜索修复（2026-11-06，须升级至 1.0.3）

- 使用上游返回的 `next_offset`、`search_id` 和 `passback` 连续翻页，不再把每页固定当成 20 条而跳过结果。
- 首次搜索合并前两页，按真实剧目 ID 去重，再按 JSTV 的每页 20 条返回；后续分页继续使用上游游标。
- 只将真实视频剧目作为搜索结果，排除讨论帖、预约帖和合集宣传卡片，读取卡片中的全部视频条目。
- 从搜索到的真实剧名识别同系列续季，按完整标题补查缺失季及后续季；每次最多补查 4 个季号，不硬编码剧名或剧目 ID。短名未收录最新季时也有机会补全。
- 完整剧名及明确季号优先展示；搜索接口失败会明确报错，不伪装成“没有搜到”。

本机实测“觉醒伪神”在首屏结果包含第 1—8 季；第 6 季为 192 集，第 8 季为 213 集。两季第 1、2 集分别完成前 4 秒音视频解码。另检查“末世选择”可返回第 1—3 季，分页结果无重复。以上为本批样本，不代表所有作品、所有季或全部分集完整验收；上游索引变化、访问失败或补查范围之外的季仍可能缺失。

## 1.0.1 播放修复（2026-11-03）

旧批量播放接口在本机实测返回 HTTP 200 空内容，导致第一集已有缓存时仍能播放、后续集数无法取址。本版将播放切换为单集 `video_model/v1/`，使用与之配套的 Gorgon / Argus / Ladon 签名和请求参数；搜索保留原 PureSign 实现。无需账号，不增加外部解析服务。

已对《末世选择，从解析神明开始成神第三季》第 1、2、3、10、50、116 集，以及第一季第 1、2 集分别完成前 4 秒音视频解码。该结果仅为抽样，不代表 116 集逐集完整验收。

## 已验证范围

2026-10-27，在 macOS 的 JSTV 1.17（30）中完成导入、搜索、1080P HEVC 硬件解码与实际播放验证；进度跳转和切集经使用者实测通过。另对三部剧各一集完成完整音视频解码测试。

其他设备尚未实际验收；是否支持取决于设备的 JSTV 版本、Node.js 运行环境及解码能力。未对全部剧集作可播保证。

## 运行方式

脚本为当前运行会话新建匿名设备身份，用于内容接口请求；身份和临时播放信息仅保留在内存中。关闭源后清除，不读取现有账号凭据，不写入本机配置。

本机视频服务只监听回环地址，随 JSTV 运行，不对局域网或公网提供服务。平台接口、视频编码或网页结构变化可能导致失效。

## 文件

- `index.js`：独立源及所需算法，内置依赖，无需额外安装 npm 包。
- `index.config.js`：空默认配置。
- 两个 `.md5` 文件：对应脚本内容校验码。

更新源文件时，需要同步更新对应的 MD5 校验码。
